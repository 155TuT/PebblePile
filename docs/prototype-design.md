## 1 入口与表现

首页直接输入，顶栏的独立图标按钮进入记录库或设置。输入区只保留输入、附件、语音和提交。记录库用时间线、记录本和语义标签组织同一批内容；记忆管理位于设置。事项的建议、实际反馈与纠正沿原记录延续。

顶栏下方使用“对话／记录”页面级分段选择，选中态表示当前方式。切换保留草稿和当前记录；右侧图标提交在对话模式下发送，在记录模式下保存。语音先转为可编辑文字，用户确认后提交。添加材料、语音和提交均为图标按钮，提供可访问名称。

页面通过位置、排版和组件状态表达层级，保留时间、来源、条件与处理结果等业务事实。普通操作使用默认凸起态；输入、页面方式和标签的选中项使用凹陷态。字号等通用分段控件沿用凹陷轨道与凸起选项，当前值由所在轨道与位置标识。“查看记录”等导航动作保持普通按钮状态。

沿用浅砂与苔绿的新拟物、霞鹜文楷 400／500、Leftist Mono Serif 400 和 Iconoir Regular。常规画板基准为 390 × 844，设置以完整长页展示，导览保留 844 高的滚动视窗；正文 16／26，页面边距 20，操作触点至少 48，底部安全区独立。系统状态栏沿用平台字体。原型以虚构资料展示，品牌图标与既定视觉方向保持一致。

## 3 主要流程

### 3.1 记录、处理与反馈

**H1 → H7 → H3 → H4 → H5 → 原记录。**

演示输入为“今天加班，晚饭想省事一点，预算二十元。”原话先保存。网络中断进入 H2，重试回到 H7；暂停进入 H8，原记录和进度保留。整理完成后给出建议，并能查看采用的认识与证据。

“最后吃了热汤面，速度够快，也很舒服。”作为本人实际体验单独保存。建议、选择和实际经历分别表达；记录结果时可选择完成或继续事项。反馈进入原记录，相关认识按证据更新。

记录模式走 **H0 → H6**。保存后是否继续整理由设置决定。新记录先进入记录库，用户可稍后归本。

### 3.2 找回与标签纠正

**L1 → L2 → L3 → L4 → L3 → L2。**

“加班晚餐”“省事”是 Agent 与本地算法产生的内容标签。组合筛选沿用人物、时间和当前标签条件；返回列表保留筛选。待核对标签通过开关明确纳入范围。

标签面板定位原话，保留起源、来源版本与算法版本。确认、修改或排除后，详情与筛选结果同步变化。人工排除针对当前记录的标签指派，原材料仍可在全部记录中找到。

### 3.3 认识的使用与纠正

**M1 → M2 → M3 → M4 → M5**；回答旁的依据可直接进入 M3，修改后返回发起入口。

演示中的“加班时，晚饭优先省事”来自 11 月 5 日和 7 日两次独立实际经历。将其改为“只在工作日加班时优先省事”时，先选择作用范围：

- **仅本次**：修改当前事项的条件，保留原有长期认识。
- **以后按此条件**：形成本人明确设置，立即停用受影响旧推断；原文与推断历史保留，相关内容继续整理。

生效页显示修改结果与整理状态。认识管理与标签分类分别处理，纠正偏好不会改写原话。

## 4 交互与异常规则

| 情况 | 原型中的表现与后续实现规则 |
| --- | --- |
| 输入方式切换 | 同一草稿、同一记录上下文；仅提交行为变化 |
| 系统听写 | 转成可编辑文字；取消或拒绝权限时保留草稿 |
| 保存与推理 | “已保存”与“正在整理”分开；断网仍能回查原文 |
| 暂停与恢复 | 暂停保留进度，继续从有效输入恢复；处理完成才显示结果 |
| 标签纠正 | 返回原详情并保留筛选；被排除的指派退出对应结果 |
| 认识纠正 | 确认前展示范围和影响；长期变更立即停用旧推断 |
| 返回与关闭 | 浮层回到触发处，跨入口纠正回到发起位置 |
| 空输入或长内容 | 空白输入禁用提交；输入最多四行，超出内部滚动，操作行固定可见；长反馈可滚动阅读 |

## 5 Paper 与本地导览

Paper 保存可编辑页面和流程图。当前 MCP 接口未提供原生点击跳转或热点 API，本轮用画布流程图表达页面关系，本地 HTML 演示点击、范围选择、草稿编辑、状态变化与返回。

导览直接从 Paper 的 JSX 和精确样式生成，动作映射引用实际节点。模拟整理完成放在画面外的导览工具区；页面中的处理状态和按钮按业务条件表达。

`assets/prototype/source/` 保存当前导出源与动作清单，`assets/prototype/index.html` 为生成结果。[生成脚本](../scripts/build-prototype-preview.py)读取静态字面量，复用本地主题；修改 Paper 后重新导出相关页面并生成导览。临时截图与验证报告留在 `.build/prototype/`，正式资产不重复保存逐屏 PNG。

本地导览没有模型、数据库、真实语音采集或系统文件选择器。搜索、记录本管理及未展开的设置分组保留入口与演示说明。系统状态、数据保存和算法效果仍需应用实现验证。在线展示权限需在团队提交前用未登录或组外账号核验。
